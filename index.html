1¿Qué es CSS?

Cascading Style Sheets: el lenguaje que controla cómo se ve el HTML: colores, tipografías, espacios y distribución. HTML pone el contenido; CSS lo viste. Pulsa el botón y compruébalo.

2Sintaxis básica

Una regla CSS dice a quién aplicar qué. Toca cada parte para inspeccionarla.

Regla = selector + { propiedad: valor; }

3Cómo añadir CSS

Atributo style. Solo para pruebas rápidas.
<p style="color: green;">Hola</p>
Etiqueta style dentro del head. Útil en una sola página.
<style>
  p { color: green; }
</style>
Archivo .css externo: lo recomendado. Un mismo archivo da estilo a todo el sitio.
<link rel="stylesheet" href="styles.css">

9Diseño responsive

      
Un diseño responsive se adapta al ancho disponible. Mueve el control: las columnas cambian con reglas condicionales (aquí con container queries; en toda la página se usan media queries con el ancho de la pantalla).

10Transiciones y animaciones
