# 🎨 Guía Interactiva de CSS · Pathdawann (2/3)

Dale estilo, color y estructura visual a la web practicando **CSS** en laboratorios interactivos donde cada cambio se refleja al instante. Un proyecto creado por **Pathdawann** para impulsar el **aprendizaje continuo**.

🔗 **Explora la guía en vivo:** [hey-aprende-css.vercel.app](https://hey-aprende-css.vercel.app/)

## 🌱 Sobre Pathdawann y el aprendizaje continuo

**Pathdawann** es mi espacio de creación, divulgación y práctica constante en desarrollo web. Creo que dominar el diseño web se vuelve mucho más claro cuando puedes experimentar con cada propiedad en vivo y ver qué ocurre en pantalla paso a paso, sin abrumarte con todo de golpe. Esta guía es el segundo escalón de esa ruta.

## 🎯 ¿Qué encontrarás en esta guía?

1. **Bases y sintaxis:** Cómo funciona la cascada, anatomía de una regla CSS y las tres formas de integrarlo en HTML.
2. **Laboratorio de selectores:** Prueba selectores de etiqueta, clase, ID, descendientes y pseudoclases sobre elementos reales.
3. **Modelo de caja y tipografía:** Controles interactivos para `padding`, `border`, `margin`, radios, fuentes y verificación de contraste WCAG en tiempo real.
4. **Layouts modernos:** Laboratorios en vivo para **Flexbox** y **CSS Grid**.
5. **Diseño responsive y movimiento:** Simulador de adaptación por ancho con *Container Queries* y *Media Queries*, transiciones, `@keyframes` y quiz interactivo con progreso guardado.

## 🛠️ Stack utilizado

* **HTML5** semántico y accesible.
* **CSS3** moderno (Custom Properties, Grid, Flexbox, Container Queries, tema claro/oscuro automático y manual).
* **JavaScript (Vanilla)** sin dependencias externas, con persistencia de progreso mediante `localStorage`.
